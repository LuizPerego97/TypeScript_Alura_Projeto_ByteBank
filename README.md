⏳ Bytebank - Sistema de Gerenciamento Bancário

📌 Sobre o Projeto
Bytebank é uma aplicação desenvolvida com TypeScript e princípios de POO para simular operações bancárias de maneira segura e eficiente. O projeto tem como objetivo demonstrar conceitos essenciais de programação orientada a objetos, herança, modificadores de acesso e boas práticas no desenvolvimento de software.

📚 Estudos e Referências

JavaScript ou TypeScript? Entenda as principais diferenças
TypeScript na prática: implemente um projeto completo com TypeScript e módulos
TypeScript: aplicando orientação a objetos no Front-end

TypeScript: uso de tipagem estática, type alias e enum para melhor organização do código.
Programação Orientada a Objetos: aplicação de herança, sobrescrita de métodos e encapsulamento com private, public e protected.
Métodos Estáticos: funções utilitárias para cálculos bancários e conversões.
Generics: criação de estruturas flexíveis e reutilizáveis.
Decorators: implementação de validações e logs de operações bancárias.
Arquitetura de Código: organização de arquivos em types e utils para melhor manutenibilidade.

Os conhecimentos adquiridos foram aplicados entre 2023 e 2025, também sendo utilizados no meu estágio na Simples Software.

🛠 Tecnologias Utilizadas

TypeScript: Linguagem principal utilizada para desenvolvimento.
Node.js: Ambiente de execução para testar e rodar o projeto.
POO: Princípios fundamentais aplicados na estrutura do sistema.

🎨 Principais Características
✔ Criação de contas bancárias com diferentes tipos de acesso e modificadores.
✔ Métodos estáticos para operações financeiras sem necessidade de instanciar objetos.
✔ Uso de herança para criação de diferentes tipos de contas (Corrente, Poupança, etc.).
✔ Implementação de validações e logs através de Decorators.
✔ Código modularizado e organizado seguindo boas práticas de desenvolvimento.
